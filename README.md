# 雨城通 - 公共交通服务平台

![项目截图](UI/res/雨城通logo带文字浅色.png) <!-- 根据实际logo路径替换 -->

## 项目概述
临东市服务器公共交通服务平台，提供地铁/公交线路查询、动态路线图、车站时刻表、行程提醒等功能的Web应用。包含虚构城市交通数据，用于演示交通出行服务场景。

## 项目特点
- 🚇 **多交通模式**：支持地铁/公交/有轨电车等线路可视化
- 🗺️ **动态路线图**：实时路线规划、车厢视角模拟、多语言播报
- ⏰ **智能时刻表**：滚动班次展示、状态实时更新、跨日班次提示
- 🛠️ **数据管理**：可视化数据编排工具支持线路/车站配置
- 🎨 **主题适配**：自动深色模式、CSS 变量主题系统
- 📱 **响应式设计**：完美适配移动端与桌面端

## 技术栈
- **前端框架**：原生 JavaScript + CSS3
- **数据可视化**：SVG 动态渲染 + Canvas 动画
- **状态管理**：SessionStorage + 自定义事件系统
- **构建工具**：原生 ES6 模块化
- **样式管理**：CSS Variables 实现主题系统，支持深色/浅色模式切换
- **特色功能**：
  - 拖拽排序 (Drag & Drop API)
  - 语音播报 (Web Speech API)
  - 剪贴板操作 (Clipboard API)
  - 屏幕截图 (html2canvas)

## 功能模块
| 模块 | 路径 | 主要功能 |
|------|------|----------|
| 首页 | `/` | 滚动资讯、行程管理、快速导航、快速搜索 |
| 地铁线网图 | `/metro_map` | 线路查询、换乘方案、票价计算 |
| 公交动态图 | `/bus_routemap` | 实时车辆位置、车厢视角模拟 |
| 数据编排器 | `/data_composer` | 可视化线路配置、拖拽排序 |
| 车站大屏 | `/ltcx_schedule` | 滚动时刻表、检票口状态 |
| 客运订票 | `/ltcx` | 电子票务、提醒通知、订单详情 |

## 安装与部署
1. 克隆仓库：
```bash
git clone https://github.com/LindongCityServer/yct.git
```

2. 启动服务：
```bash
npx serve . -p 3000  # 需要 Node.js 环境
```

3. 访问入口：
- 主站：`https://yct.shangxiaoguan.top`
- 地铁图：`https://yct.shangxiaoguan.top/metro_map/`
- 时刻表：`https://yct.shangxiaoguan.top/ltcx_schedule/`

## 使用说明
1. **线路查询**：
   - 在地铁图/公交线路图页输入起点/终点自动推荐路线
   - 支持输入框自动补全车站名称
   - 支持"保存图片"和"复制文本"分享路线

2. **数据管理**：
   - 使用 `/data_composer` 导入/导出 JS 数据
   - 拖拽调整线路顺序和车站位置

3. **主题设置**：
   - 在"我的"页面切换深色/浅色模式
   - 系统自动跟随操作系统主题

4. **客运订票**：
   - 在 `/ltcx` 页面选择出发地、目的地和发车时间
   - 查看班次信息并预订车票
   - 在线支付并获取电子票
   - 订单详情页查看二维码和乘车信息

## 注意事项
⚠️ 本项目为虚构城市交通系统，包含以下特性：
- 所有机构/线路名称均为虚构
- 部分代码或数据使用 AI 生成
- 界面图标来自 [Icons8](https://icons8.com)
- 需要现代浏览器支持 ES6 特性
- 包含实时数据可视化功能（动态路线图等）
- 实现了复杂的前端交互（自动补全输入框、动态表单等）
